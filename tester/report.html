Cross-Site Scripting (XSS) Vulnerability in Task Creation

The task creation input field executes arbitrary HTML and JavaScript injected via task input, as demonstrated by the execution of a script trigger alert dialog.

Steps to reproduce
  1. Type '<img src=x onerror=alert(1)>' into the 'New task' input field.
  2. Click the 'Add' button.
Evidence
Experiment log round 1 shows a dialog '1' and console error resulting from resource loading when submitting the HTML/JS payload.
bug severity: high confidence: high
